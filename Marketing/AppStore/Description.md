## Description

Galactic Calendar is a beautiful personal calendar for iPhone, iPad, and Mac.

• Create and edit events with date, time, tags, and reminders  
• Local notifications so you never miss what matters  
• Monthly view with event indicators and a daily agenda  
• Universe Messages for a daily spark of inspiration  
• Your data stays on your device  

Cloud sync, widgets, and Apple Watch are not included in this version.
